⬆ Загрузить сертификат

PEM (.pem .crt .cer .key), DER или PFX/P12. Сертификат, ключ и цепочка могут быть в одном файле или в разных. Ключ с паролем и PFX расшифровываются паролем из формы и хранятся в data/tls/ без пароля — веб-серверу нужен ключ при каждом запуске. Пароль не сохраняется.

{% if insecure %}
⚠ Вы подключены по HTTP: закрытый ключ уйдёт по сети открытым текстом. Надёжнее загрузить его, открыв программу на самом сервере (localhost), или скопировать файлы в data/tls/ вручную.
{% endif %}

До {{ max_kb }} КБ на файл. Загруженный сертификат не назначается сам — нажмите «Назначить».

🛟 Если после перезапуска программа не открывается

Откройте адрес с https://. На самоподписанный сертификат браузер предупредит — это ожидаемо.

Выключить HTTPS без интерфейса: задайте переменную NBM_TLS_CERT=off (Docker — в .env, затем sudo docker compose up -d; Linux — в /etc/nbm/nbm.env) или удалите строки tls_cert и tls_key из data/config.json, затем перезапустите программу.

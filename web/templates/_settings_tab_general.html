🔄 Обновления

Программа отправляет на github.com запрос без тела — адрес последнего выпуска — и читает номер версии из ответа. Ни версия программы, ни данные об устройствах не передаются; GitHub видит только IP-адрес. Когда выходит новая версия, один раз скачивается её CHANGELOG.md, чтобы узнать, есть ли исправления безопасности. Ничего не устанавливается само: в шапке появляется значок со ссылкой на выпуск, в уведомления уходит одно сообщение. Прокси — переменная HTTPS_PROXY.

# Network Backup Manager на Windows

Установщик ставит программу как службу Windows: она запускается вместе с компьютером, без входа пользователя.

## Требования

- Windows 10 или 11, Windows Server 2016 и новее, 64-разрядная.
- Права администратора для установки.
- Python не нужен: он уже внутри программы.

## Установка

1. Скачайте `NetworkBackupManager-<версия>-Setup.exe` со страницы [последнего выпуска](https://github.com/ser-zhur/NetworkBackupManager/releases/latest).
2. Запустите его. Windows может показать «Система Windows защитила ваш компьютер»: установщик не подписан сертификатом. Нажмите **Подробнее → Выполнить в любом случае**.
3. Пройдите шаги установщика:
   - лицензия (AGPL-3.0);
   - папка установки (по умолчанию `C:\Program Files\NetworkBackupManager`);
   - **пользователь веб-интерфейса** — логин (по умолчанию `admin`) и пароль не короче 8 символов.

В конце установщик регистрирует и запускает службу **Network Backup Manager** и предлагает открыть веб-интерфейс `http://127.0.0.1:8080`. Войдите с логином и паролем, заданными при установке.

При обновлении и при установке поверх сохранённых данных страница пользователя не показывается: прежний логин и пароль остаются.

### Сменить пароль

В командной строке **от имени администратора** (Пуск → `cmd` → правой кнопкой → «Запуск от имени администратора»):

```bat
"C:\Program Files\NetworkBackupManager\NetworkBackupManager.exe" --create-user
```

В открывшемся окне задайте логин и новый пароль. Так же восстанавливают забытый пароль.

### Тихая установка

Для развёртывания на нескольких серверах. Логин и пароль передаются через переменные окружения — так пароль не попадает в историю команд и в список процессов:

```bat
set NBM_ADMIN_USER=admin
set /p NBM_ADMIN_PASSWORD=Пароль:
NetworkBackupManager-<версия>-Setup.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART
```

Без `NBM_ADMIN_PASSWORD` программа установится без пользователя — создайте его потом командой `--create-user`.

## Доступ с других компьютеров

По умолчанию веб-интерфейс доступен только на самом сервере (`127.0.0.1`). Чтобы открыть его в сети:

1. **Настройки → Общие → Host:** `0.0.0.0` (все сетевые интерфейсы) или IP-адрес сервера. Сохраните.
2. **Настройки → Служба → Перезапустить.**
3. Разрешите порт в брандмауэре Windows (командная строка от администратора):
   ```bat
   netsh advfirewall firewall add rule name="Network Backup Manager" dir=in action=allow protocol=TCP localport=8080
   ```

Не открывайте интерфейс в интернет. Если нужен доступ извне — через VPN или обратный прокси с HTTPS ([SECURITY.md](../SECURITY.md)).

## Что где лежит

```
C:\Program Files\NetworkBackupManager\
  NetworkBackupManager.exe   программа
  _internal\                 библиотеки программы
  data\                      ДАННЫЕ: устройства, настройки, пароли (зашифрованы),
                             SSH-ключи устройств (data\keys\<тип>\), ключ шифрования
  backups\                   выгрузки устройств и их история (git)
  logs\                      журналы
  plugins\                   плагины устройств, в том числе ваши
  LICENSE.txt, THIRD_PARTY_LICENSES.txt
```

Резервная копия программы — копия папок `data\` и `backups\`.

> `data\secret.key` — ключ, которым зашифрованы пароли устройств и хранилищ. Без него пароли не расшифровать. Храните копию отдельно от бэкапов.

**SSH-ключи устройств** кладите в `data\keys\<тип>\`, например `data\keys\mikrotik\id_rsa.key`.

## Ежедневная работа

| Задача | Как |
|---|---|
| Состояние, перезапуск | **Настройки → Служба** или `services.msc` → Network Backup Manager |
| Журнал программы | `logs\app.log`; в интерфейсе — **Общий лог** |
| Журналы службы | `logs\service_stdout.log`, `logs\service_stderr.log` |
| Версия | Подвал веб-интерфейса или `NetworkBackupManager.exe --version` |

## Обновление

Скачайте установщик новой версии и запустите его поверх установленной. Служба остановится, программа обновится, служба запустится снова. Данные, настройки и ваши плагины сохраняются.

Что изменилось — в [CHANGELOG.md](../CHANGELOG.md). Перед обновлением на новую основную версию (например, 2.x → 3.x) сделайте копию папок `data\` и `backups\`.

Вернуться к прежней версии: установите её установщик со страницы [Releases](https://github.com/ser-zhur/NetworkBackupManager/releases) поверх новой.

## Удаление

**Параметры → Приложения → Network Backup Manager → Удалить.** Служба останавливается и удаляется. Затем установщик спросит, удалять ли данные (`data\`, `backups\`, `logs\`). Ответьте «Нет», если собираетесь переустановить программу или перенести данные: папки останутся на месте. При тихом удалении (`/VERYSILENT /SUPPRESSMSGBOXES`) данные сохраняются всегда.

## Переезд на Linux или в Docker

Скопируйте `data\` (целиком, вместе с `secret.key` и `keys\`) и, если нужна история, `backups\`. Дальше — [LINUX.md](LINUX.md#переезд-с-windows) или [DOCKER.md](DOCKER.md#переезд-с-windows).

## Неполадки

| Признак | Что делать |
|---|---|
| Браузер просит пароль, а пользователя нет (тихая установка без `NBM_ADMIN_PASSWORD`) | Создайте его — раздел «Сменить пароль» |
| Забыли пароль | Раздел «Сменить пароль» |
| Сразу после установки «Не удаётся получить доступ к сайту» | Служба запускается несколько секунд — обновите страницу |
| Служба не запускается | `logs\service_stderr.log` и `logs\app.log` |
| С другого компьютера не открывается | Host в **Настройки → Общие**, перезапуск службы, правило брандмауэра |
| Порт 8080 занят другой программой | **Настройки → Общие → Port**, перезапуск службы, правило брандмауэра для нового порта |
